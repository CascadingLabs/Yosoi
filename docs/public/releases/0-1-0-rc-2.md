# Yosoi 0.1.0-rc.2

## Summary

Yosoi 0.1.0-rc.2 repairs release candidate packaging and documentation publication. This candidate exercises the complete installed-artifact matrix before publishing checksummed SDK and CLI artifacts on GitHub.

## Highlights

### Reliable interpreter selection

Release jobs select CPython through UV, including Python 3.15 and free-threaded interpreters. Absolute interpreter paths avoid collisions with the Python source directory during source distribution extraction, native builds, and installed-package tests.

## Improvements

Versioned docs publication accepts numbered RC versions. Candidate GitHub artifacts and their documentation bundle can be published after all artifact checks pass.

## Known limitations

RC packages are distributed through GitHub only. Crates.io and PyPI publication for the final beta remain gated on resolving the browser dependency distribution strategy. Browser execution requires separate platform certification.

## Upgrading

Install the candidate from its GitHub release assets using explicit versions. Rust metadata uses `0.1.0-rc.2`; Python distribution metadata uses `0.1.0rc2`. There are no API migration changes from rc.1. The final beta will use `0.1.0` and pass separate registry publication checks.

## Full changelog and contributors

Thanks to everyone who contributed to this release.
