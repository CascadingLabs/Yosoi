# Yosoi 0.1.0-rc.5

## Summary

This candidate adds PyPI publication and clean registry-install verification for the Python SDK. Users install the single `yosoi` package; the release keeps the existing Rust and Python SDK APIs.

## Highlights

### Python publication and installation checks

Verified Python wheels publish independently of crates.io. All 30 platform/interpreter installations must pass against PyPI before GitHub assets, Chromium images, and candidate docs publish. Free-threaded installations check that importing the extension keeps the GIL disabled.

## Improvements

Rust CI partitions the complete default and all-feature test suites across isolated runners and merges their coverage. Native release tests share release-profile dependencies with the CLI build, and verified source timestamps support compiled-cache reuse. CI retains source-line backtraces with smaller debug artifacts.

## Fixes

Candidate docs publication now handles intentionally skipped Rust registry jobs. Docs recovery reuses the released, checksummed bundle, and the publisher installs its locked dependencies for every publication path.

## Known limitations

Rust crates.io distribution remains a separate final-beta prerequisite. The candidate's installed-artifact and registry checks do not promote a new browser/controller certification tuple.

## Upgrading

For the Python preview, select the candidate explicitly with `uv add yosoi==0.1.0rc5`. Existing RC4 SDK code requires no API changes. Final `0.1.0` uses its own version and registry verification.

## Full changelog and contributors

Thanks to everyone who contributed to this release.
