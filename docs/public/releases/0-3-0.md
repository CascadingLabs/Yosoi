# Yosoi 0.3.0

## Summary

Yosoi 0.3.0 makes Python Contracts use normal Pydantic validation and gives Rust and Python a shared workflow for saving and inspecting browser evidence. The Concepts series follows one QScrape product from local HTML through browser work and offline inspection.

## Highlights

### Validated Python records

`Product.extract(document)` and `ys.extract(document, Product)` return validated Pydantic models. Field and model validators, custom types, defaults and constraints run automatically. Use `extract_report` to inspect accepted records, rejected candidates and retained diagnostics; `ExtractionPolicy` bounds the work and controls rejection handling.

### Archive and inspect completed browser work

Python can save Documents, compiled Plans and AutomationRecords through the existing Rust Archive backend. Both languages can retain a Flow's results, cleanup receipts and observations, then reopen them without launching another browser. Bounded View pages preserve observation identity and reject foreign or changed continuation sources.

### Complete binary response bodies

Request attempts expose their complete retained body bytes and content type independently of searchable Documents. Binary responses can remain useful even when no text Document can be projected. Truncated or unavailable bodies are not presented as complete.

### Installation-aware CLI maintenance

The CLI supports self update and uninstall for standalone, UV and Cargo installations, with installation-specific behavior. Documentation now presents the supported installation paths and a progressive worked Concepts series.

## Known limitations

The local Archive backend currently supports Unix filesystems. Windows returns an explicit unsupported-platform error. Saved evidence does not restore live browser authority or replay effects. Arbitrary Python/Pydantic objects are not portable Rust archive values. Public remote-CDP attachment and recursive Contract roots remain deferred.

## Upgrading

Update the Rust SDK dependency and Python `yosoi` package to 0.3.0. CLI users install or upgrade `yosoi-cli`, rather than the legacy Python CLI package.

Python Contract extraction now returns validated model instances. Code using the former `Contract.extract(located)` intermediate pipeline should use `Contract.assemble(located)`; use `Contract.extract(document)` for the convenient validated path. Rust's explicit Contract extraction and validation pipeline remains available.
