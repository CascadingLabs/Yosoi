# Yosoi 0.1.0-rc.7

## Summary

This candidate corrects Python source distribution licensing and prepares the browser dependency stack for Rust registry publication. Public SDK calls and existing browser environment producer identities remain unchanged.

## Highlights

### Complete Python source distributions

The source archive explicitly includes the Apache license declared in its package metadata. Release verification checks every declared license file before uploading. RC6's 15 wheels reached PyPI, but its source archive was rejected; RC7 uses a new version and preserves the previous candidate's immutable files.

### Yosoi-owned Rust browser packages

The browser core and patched Chromiumoxide/CDP packages use Yosoi-owned registry names. Rust import names and the canonical browser producer identity remain compatible. Consumers continue to install the public `yosoi` SDK; internal dependencies are resolved by Cargo.

## Publication checks

All native and wheel builds, installed-artifact tests, artifact verification, PyPI publication, and 30 clean PyPI installation checks remain required before the candidate completes. Free-threaded registry installs verify that importing the extension leaves the GIL disabled.

## Known limitations

Rust registry publication remains a separate prerequisite for final `0.1.0`. This candidate does not promote a new browser certification tuple.

## Upgrading

Select the Python preview explicitly with `uv add yosoi==0.1.0rc7`. Existing SDK calls require no API changes. Final `0.1.0` uses its own release version and publication verification.

## Full changelog and contributors

Thanks to everyone who contributed to this release.
