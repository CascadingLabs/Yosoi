# CAS-300 Capture Bundle

`CaptureBundle` is an immutable in-memory aggregate containing a finalized `WebCapture` and payloads keyed by typed `WebArtifactRef`. Input is intentionally a finalized `WebCapture`; callers must complete capture validation before constructing a bundle. `CaptureBundleBuilder::insert` validates each payload before publishing it: the reference must be present in the finalized manifest, metadata must describe retained/truncated bytes, and both exact retained length and SHA-256 must match. Finalization repeats these checks and requires every retained/truncated artifact to have a payload, while rejecting bytes for discarded or unavailable artifacts. Payload insertion errors publish nothing and do not reserve the reference, so callers may correct and retry them. Finalization consumes the builder on either success or error, preventing a partially validated bundle from being reused or published.

Retrieval is deliberately narrow and offline: `payload` returns a borrowed byte slice by typed reference. There is no remote storage, archive, database, provider hierarchy, or extraction API. `CaptureBundle` has no Serde implementation: it is not a wire/archive format and is published only through the validated builder. Complete and truncated semantics remain in `WebArtifactMetadata` and are not inferred or rewritten by the bundle.
