# Trivial Controls

Controls answer whether a pruner is fundamentally broken before an adversarial workload is diagnosed.

- `html/`: Books to Scrape or an equivalent small SSR fixture.
- `dom/`: TodoMVC or an equivalent simple SPA fixture.
- `ax/`: a compact, correct ARIA fixture.
- `network/`: a deterministic 50-request normalized trace.

Each control still uses a manifest, ground-truth sidecar, frozen artifacts, and exact evidence oracles.
