# Multimodal boss fixtures

These are real-ish frozen page captures for the first multimodal smoke/bench runs. The HTML was acquired with Yosoi's headless fetcher from Wikipedia and rasterized locally with Chromium.

- `web-scraping.png`: page title and legal/ethical concerns
- `browser-automation.png`: browser automation use cases
- `tailscale.png`: network type and topology
- `manifest.json`: source URLs and deterministic questions

The PNGs are benchmark inputs, not authoritative ground truth. Keep the source URL and capture date with any result artifact; Wikipedia content can change.
