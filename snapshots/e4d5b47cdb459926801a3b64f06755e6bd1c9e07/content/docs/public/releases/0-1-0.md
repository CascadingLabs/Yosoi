# Yosoi 0.1.0

## Summary

Yosoi 0.1.0 is the first beta of the public Rust and Python SDKs. Install the same SDK through Cargo or PyPI, with versioned documentation and separate Chromium CDP runtime images.

## Highlights

### One public SDK for each language

Rust consumers install `yosoi` through Cargo; browser support packages are resolved as dependencies under Yosoi-owned registry names. Python consumers install `yosoi` through PyPI, including its compiled Rust extension.

### Python 3.12 through 3.15

Binary wheels cover Linux x86_64 and aarch64, macOS Intel and Apple Silicon, and Windows x86_64. Python 3.14 and 3.15 free-threaded builds have dedicated compatibility coverage; release checks verify that importing the extension leaves the GIL disabled.

### Versioned docs and Chromium runtimes

The release workflow publishes documentation and API references tied to the release source commit. The separate Chromium CDP images provide headless and headful browser runtimes; they do not package application code.

## Known limitations

This is a beta release. Browser support follows the documented Chromium/CDP baseline; passing SDK release checks does not certify a new browser tuple. Package registries publish independently, so release completion also requires checking installed packages and the documentation workflow.

## Upgrading

Install the final beta with `cargo add yosoi@0.1.0` or `uv add yosoi==0.1.0`. For Rust browser capture, enable the SDK's `browser` feature with `cargo add yosoi@0.1.0 --features browser`. Existing release-candidate SDK calls require no API changes. Python resolves the compiled extension automatically; no separate Rust installation is required for supported binary-wheel platforms.
