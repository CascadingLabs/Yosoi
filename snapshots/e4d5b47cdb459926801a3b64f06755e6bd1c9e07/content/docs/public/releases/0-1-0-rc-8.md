# Yosoi 0.1.0-rc.8

## Summary

This candidate completes verification of the Python registry publication path. It retains RC7's source-distribution license fix, Yosoi-owned Rust browser packages, and public SDK behavior.

## Highlights

### Clean PyPI installations run for candidates

After PyPI upload succeeds, the release workflow runs all 30 supported platform/interpreter combinations against clean registry installations. Intentionally skipped Rust registry publication for candidates no longer prevents those tests from starting. Failed or canceled upload prerequisites still block the tests and downstream publication.

## Publication checks

All native and wheel builds, installed-artifact tests, artifact verification, PyPI upload, and clean PyPI installation checks remain required before candidate completion. Free-threaded installations verify that importing the extension leaves the GIL disabled. Chromium container, GitHub release, and documentation publication wait for those installation checks.

## Known limitations

RC7's 15 wheels and source archive are available on PyPI, and its 30 installed-artifact tests passed. Its registry-installed tests and downstream publication were skipped by a workflow condition. Rust registry publication remains a separate prerequisite for final `0.1.0`; this candidate does not certify a new browser tuple.

## Upgrading

Select this Python preview explicitly with `uv add yosoi==0.1.0rc8`. Existing SDK calls require no API changes. Final `0.1.0` uses its own release version and publication verification.

## Full changelog and contributors

Thanks to everyone who contributed to this release.
