# Yosoi 0.1.0-rc.6

## Summary

This candidate retries Python registry publication with the Windows Python 3.12 fixture cleanup included in the tagged source. SDK cancellation and sibling-request behavior are unchanged.

## Highlights

### Consistent fixture cleanup across supported Python versions

The cancellation test tracks every accepted connection and closes its fixture-owned transports after all SDK assertions finish. The public transport API works on Python 3.12 and newer. Windows diagnostics passed the complete installed-wheel suite on 3.12, 3.14t, and 3.15t using the existing RC4 binaries.

## Publication checks

All native and wheel builds, installed-artifact tests, artifact verification, PyPI publication, and 30 clean PyPI installation checks remain required before the candidate completes. Free-threaded registry installs verify that importing the extension leaves the GIL disabled.

## Known limitations

RC5 did not publish to PyPI because its tagged Windows Python 3.12 fixture timed out during teardown. Its immutable tag remains available. Rust registry packaging is a separate prerequisite for final `0.1.0`; candidate artifact tests do not promote a browser certification tuple.

## Upgrading

Select the Python preview explicitly with `uv add yosoi==0.1.0rc6`. Existing SDK calls require no API changes. Final `0.1.0` uses its own release version and publication verification.

## Full changelog and contributors

Thanks to everyone who contributed to this release.
