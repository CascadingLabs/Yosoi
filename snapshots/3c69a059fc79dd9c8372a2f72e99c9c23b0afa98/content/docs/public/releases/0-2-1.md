# Yosoi 0.2.1

## Summary

Yosoi 0.2.1 makes the CLI available as a prebuilt tool. Install it through
PyPI with `uv tool install yosoi-cli`, or use the Linux/macOS shell installer
and Windows PowerShell installer. These paths download binaries and do not
require Rust or Cargo. Manual Cargo installation remains supported.

The release also consolidates the documentation into shared concepts,
task-oriented recipes, and separate Rust and Python references. Public API
explanations now come from source and are checked during development.

## Highlights

### Install the CLI without a compiler

The `yosoi-cli` PyPI package installs the `yosoi` executable without the Python
SDK or its dependencies. Run a one-off command with
`uvx --from yosoi-cli yosoi --help`, or keep the tool installed with
`uv tool install yosoi-cli`.

GitHub release assets include `install.sh` and `install.ps1`. The installers
choose the correct native archive, verify its release checksum and version,
and install the executable. Both support a pinned version and custom
installation directory. Rerun the installer to upgrade.

See [CLI installation](../cli/index.md) for commands, platform requirements,
upgrades, removal and the manual Cargo path.

### Clearer documentation and source API coverage

Learning pages explain shared behavior once, with Rust and Python examples
where both support the task. The cookbook covers acquisition, representations,
typed extraction, assertions, bounded waits, JavaScript and failure inspection.
CLI pages cover Requests, Locate, Map, Search and Policy.

The Reference sidebar groups Rust and Python declarations by module and kind.
Generated pages retain source explanations, method signatures, fields,
ownership and cancellation details. Rust enforces public documentation and
Python checks Google-style docstrings. Release history groups patch versions
under their minor release family.

The Contract derive helper now shares the workspace version. This release uses
`yosoi-contracts-derive` 0.2.1, and `cargo xtask bump-version` synchronizes future
first-party package versions and exact dependency requirements together.

## Known limitations

Prebuilt CLI releases cover Linux and macOS on x86-64 and ARM64, and Windows
on x86-64. Linux requires glibc 2.39 or newer; macOS requires 11.0 or newer.
Other targets can use manual Cargo installation with native build prerequisites.
Chrome or Chromium Stable must be installed separately for browser operations.
CLI installation checks do not establish browser certification on every platform.

## Upgrading

For the current CLI, use `uv tool install yosoi-cli`. If `uv tool list` shows
the legacy `yosoi` tool, remove it first with `uv tool uninstall yosoi`.
The `yosoi` PyPI package continues to supply the Python SDK; application
projects use `uv add yosoi==0.2.1`.

Existing CLI tool installations upgrade with `uv tool upgrade yosoi-cli`.
Script installations upgrade by rerunning the installer. Cargo installations
continue to use `cargo install yosoi --features cli --bin yosoi --locked`.

Rust projects can update to `yosoi` 0.2.1. Projects depending directly on the
Contract derive crate should also update that dependency to 0.2.1.
