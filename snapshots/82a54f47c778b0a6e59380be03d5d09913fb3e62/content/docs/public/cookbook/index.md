# Cookbook

Choose a task, follow its code, and check the result. Focused guides and complete recipes live together here.

| Task                                                  | What it teaches                                   |
| ----------------------------------------------------- | ------------------------------------------------- |
| [Fetch a page](fetch-a-page.md)                       | Acquire and inspect a known URL                   |
| [Choose a representation](choose-a-representation.md) | Match input evidence to the task                  |
| [Choose a locator](choose-a-locator.md)               | Match queries to the available representation     |
| [Extract structured data](extract-structured-data.md) | Produce typed, validated records                  |

| [Save and reuse](save-and-reuse.md)                   | Repeat evaluation without another request         |

Use controlled local inputs for processing examples. Network and browser recipes also depend on the site and runtime environment.

Check the intended business result. Completing a Flow or dispatching a click is only one part of that proof.
