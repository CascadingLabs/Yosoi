`yosoi.outcomes.U32`

```python
U32 = Annotated[int, Field(strict=True, ge=0, le=(1 << 32) - 1)]
```

Strict integer from zero through the u32 maximum. Booleans, floating-point values,
and numeric strings are not coerced.
