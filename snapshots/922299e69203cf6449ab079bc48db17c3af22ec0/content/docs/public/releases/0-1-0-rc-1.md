# Yosoi 0.1.0-rc.1

## Summary

Yosoi 0.1.0-rc.1 is the first release candidate for the Rust-backed Python SDK. It exercises the release pipeline before the final 0.1.0 beta, including separate Python 3.15 and free-threaded wheels.

## Highlights

### Rust and Python SDKs

Python callers can use `import yosoi` with Pydantic models and receive structured contract results. The SDK parity checks cover the public capabilities and outcomes shared with Rust. CPython 3.12 through 3.15 is supported, including free-threaded 3.14 and 3.15.

## Fixes

Pages with non-UTF-8 encodings are decoded correctly, and `ys.crawl(limit=N)` enforces a page cap.

## Known limitations

Registry publication requires resolving the browser dependency distribution strategy. Browser execution also requires separate platform certification; a passing packaging matrix does not certify browser compatibility on every operating system.

## Upgrading

This candidate introduces the Rust-backed Python SDK. Users upgrading from the earlier alpha should review the public Python API and contract examples before migrating. Cargo packages use version `0.1.0-rc.1`; Python packages use `0.1.0rc1`. Use an explicit candidate version when installing. The final beta will use version `0.1.0`.

Thanks to everyone who contributed to this release.
