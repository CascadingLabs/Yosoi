# Yosoi 0.1.1

## Summary

Yosoi 0.1.1 brings the Rust runtime into one `yosoi` crate while keeping its implementation modular. Rust and Python users keep the existing public SDK calls, and the command-line interface is available from the same Cargo package.

## Highlights

### One runtime package

Contracts, documents, extraction, policy, archives, acquisition, and the browser adapter now live behind private modules in `yosoi`. The derive helper and patched Chromiumoxide dependencies retain separate versions and resolve automatically; users do not need to install them separately. Unchanged support packages are verified and reused on subsequent SDK releases.

### Optional command-line interface

Install the CLI with `cargo install yosoi --version 0.1.1 --features cli`. Library users can keep the default feature set or enable `browser` for Chromium acquisition.

### Existing SDK and archive contracts

The public Rust namespaces and Python API remain available. Existing archive writer and browser controller identities are preserved independently of the SDK's package version. Python wheels retain support for CPython 3.12 through 3.15, including the supported free-threaded interpreters.

## Upgrading

Use `cargo add yosoi@0.1.1` or `uv add yosoi==0.1.1`. For Rust browser acquisition, use `cargo add yosoi@0.1.1 --features browser`. Existing public SDK calls require no changes. Development tools that imported implementation crates directly now use the private component sources through a development-only adapter.
